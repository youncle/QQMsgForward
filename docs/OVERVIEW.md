# QQMsgForward 项目全库解剖

## 一、项目定位
基于 LLOneBot v7.11.4 的 QQ 群消息实时转发系统，Python 胶水层 + Node.js 运行时架构，通过 OneBot v11 HTTP POST 协议通信。

## 二、整体架构

```
start.vbs ---> pythonw tray.py ---> Splash 启动画面
                        |
              +---------+---------+
              |         |         |
           LLBot-1   LLBot-2   LLBot-N
           port3000    3001     3000+N
              |         |         |
              +----+----+---------+
                   v HTTP POST /webhook
            Flask Forward Service 9090
                   |
         +---------+---------+
         v         v         v
     目标群1    目标群2    目标群N
```

## 三、文件职责

| 文件 | 行数 | 职责 |
|---|---|---|
| tray.py | ~750 | 主控：托盘、LLBot 启停、Flask 守护、配置窗口 |
| forward.py | ~242 | 转发：WebHook 接收、去重、限流、1 秒延迟 |
| filter.py | ~171 | 过滤：QR 解码、图片规则、联系方式检测 |
| qr_decoder.py | ~136 | 解码：图片拉取、pyzbar 解码、LRU 缓存 |
| settings.py | ~261 | 配置面板：转发/过滤规则 CRUD |
| wizard.py | ~234 | 向导：4 步引导、居中布局、配置生成 |
| splash.py | ~67 | 动画：无边框启动进度浮窗 |

## 四、核心流程

### 4.1 启动链路

```
start.vbs -> pythonw tray.py
  |-> Splash 进度窗
  |-> 查杀残留进程
  |-> 校验 config.json，缺失则唤起向导
  |-> 循环启动多 LLBot 实例
  |   |-> 主实例原目录，多实例复制独立目录
  |   +-> 轮询 /get_login_info 探测 QQ 登录
  |-> 后置全量探测，获取 QQ 到端口映射
  |-> 后台启动 Flask(9090)
  +-> 初始化托盘 + 主窗口(minsize 1024)
```

### 4.2 转发流水线

```
QQ 群消息 -> LLBot -> POST /webhook
  |-> 过滤：仅群聊、跳过自身
  |-> 匹配规则
  |-> 去重 + 限流
  |-> 延迟 1 秒
  |-> 三层过滤(QR码/图片/联系方式)
  +-> 推送到目标群
```

## 五、过滤系统

```
should_filter()
  |
  | log_only -> 仅记录不拦截
  v
+----------+
| 第1关    | QR 解码：pyzbar 解码二维码内容
| QR 解码  | 命中黑词/域名/联系方式 -> 拦截
+----+-----+
     |
     v 未命中
+----------+
| 第2关    | check_qrcode_ad()
| 图片规则 | 三模式(默认仅图片+关键词)
+----+-----+
     |
     v 未命中
+----------+
| 第3关    | 关键词 + 正则
| 联系方式 | 手机/QQ/微信/邮箱
+----+-----+
     |
     v 未命中 -> 放行
```

## 六、多实例管理

| 实例 | 目录 | API 端口 | WebUI |
|---|---|---|---|
| 0 | LLBot-CLI-Win-x64 | 3000 | 3080 |
| 1 | LLBot-CLI-Win-x64-2 | 3001 | 3081 |
| N | LLBot-CLI-Win-x64-(N+1) | 3000+N | 3080+N |

## 七、异常处理

| 场景 | 处理 |
|---|---|
| 端口占用 | 启动前查杀 |
| 配置缺失 | 向导自动创建 |
| 配置损坏 | 弹窗重建 |
| LLBot 目录缺失 | 弹窗退出 |
| 机器人未登录 | 弹窗提醒，服务继续 |
| API 失败 | 切换下一机器人 |
| HTTP 5xx | 3 次重试 |
| pyzbar 缺失 | 降级跳过解码 |
| 日志 | 按天轮转，保留 2 份 |
