# 拦截模式说明文字显示

## 目标
在 QR码过滤的「拦截模式」下拉框右侧动态显示当前选中模式的说明文字，帮助用户理解每种模式的含义。

## 方案
在 `settings.py` 中：
1. 新增 `MODE_DESCRIPTIONS` 映射表（中文显示值 → 说明文字）
2. 在下拉框右侧添加 `ttk.Label` 显示说明
3. 绑定 `<<ComboboxSelected>>` 事件，切换模式时更新说明文字
4. 初始化时根据当前存储值显示对应说明

## 三种模式说明文案

| 模式显示值 | 说明文字 |
|---|---|
| `仅关键词图片` | 仅拦截同时包含图片和关键词的消息 |
| `拦截纯图片` | 额外拦截无文字说明的纯图片消息 |
| `拦截所有图片` | 拦截所有含图片的消息 |

## UI 布局

```
拦截模式 [下拉框▼]  仅拦截同时包含图片和关键词的消息
```

说明标签紧跟在下拉框后面，随模式切换动态更新。

## 改动文件
- `settings.py` — 仅此一个文件

## 不改动
- `filter.py` — 逻辑不变
- `wizard.py` — 无变化
- `config.json` — 存储格式不变
