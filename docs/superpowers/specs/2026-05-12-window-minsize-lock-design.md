# 窗口默认尺寸与最小尺寸锁定

## 问题

- 默认窗口尺寸硬编码为 `1100x750`，不匹配实际布局的渲染尺寸
- 未设置最小尺寸限制，窗口可被缩到极小导致界面不可用

## 设计

### tray.py — 动态捕获默认尺寸 + 设置 minsize

**1. 替换硬编码默认尺寸：**
- 移除 `'1100x750'` 硬编码
- 首次运行（无已保存 geometry）时，先让 tkinter 自动布局，再用 `update_idletasks()` + `winfo_geometry()` 捕获实际渲染尺寸
- 将该尺寸写入 `.window_state.json` 作为默认值

**2. 设置最小尺寸：**
- 在 geometry 确定后立即调用 `root.minsize(width, height)`
- 用户可拉大窗口，不可缩小到基准尺寸以下

**3. 还原窗口时同步设置 minsize：**
- 无论首次还是后续启动，还原 geometry 后都从 geometry 字符串解析宽高设置 minsize

## 改动文件

| 文件 | 改动 |
|------|------|
| tray.py | ~15 行（默认尺寸逻辑 + minsize 设置） |

## 验证

- 首次启动：窗口按布局自然尺寸显示，无法缩小到该尺寸以下
- 后续启动：恢复上次保存的尺寸，同样受 minsize 限制
- 用户可向右/向下拉大窗口，缩小操作被限制在 minsize
