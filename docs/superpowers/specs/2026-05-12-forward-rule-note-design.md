# 转发规则备注功能

## 概述
为每条转发规则增加可选备注字段，让用户用人类可读的标签区分群号。

## 数据格式

### 新格式
```json
"forward_rules": {
  "1079264158": {
    "targets": ["1080631149"],
    "note": "产品群→研发群"
  }
}
```

### 旧格式兼容
加载 config.json 时检测值是否为 `list`，若是则自动迁移为 `{"targets": list, "note": ""}`。用户无感知。

## UI 改动

在设置页面"转发规则"区域，源群和目标群输入框下方新增"备注"输入框：

- 新增规则时：三个字段一起保存
- 选中已有规则时：三个字段一起回填
- 列表显示规则：有备注显示备注内容，无备注回退显示 `源群 → 目标群`

## 涉及文件

| 文件 | 改动 |
|------|------|
| settings.py | 新增备注 Entry、列表显示逻辑、保存/回填逻辑、旧格式迁移（`migrate_rule_format`） |
| config.json | 无需手动改，保存时自动写为新格式 |

## 边界情况

- 旧规则无备注 → 列表回退显示群号，备注输入框留空
- 备注为空字符串 → 等同于无备注
- 删除规则 → 整个对象删掉，备注随之清除
