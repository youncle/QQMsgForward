## Context

当前 `tray.py` 中的 `create_icon_image()` 函数使用 PIL 绘制聊天气泡+双箭头图标（64x64 RGBA），形状粗糙、视觉效果简陋。图标需在系统托盘中以 16x16~64x64 的实际显示尺寸呈现，三种颜色状态（绿/红/黄）。

## Goals / Non-Goals

**Goals:**
- 将图标从聊天气泡+箭头风格改为中性灰圆点+彩色外圈风格
- 保持 PIL 程序化生成，无外部资源依赖
- 保持函数签名 `create_icon_image(color: str = 'green')` 不变
- 三种状态颜色方案延续现有：绿(#4CAF50)、红(#F44336)、黄(#FFC107)

**Non-Goals:**
- 不改图标尺寸（保持 64x64）
- 不改颜色逻辑或状态机
- 不改调用方代码（icon 更新、menu 等全部不变）
- 不引入外部图标文件

## Decisions

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 视觉风格 | 气泡 vs 圆点 | 圆点+外圈 | macOS 风格状态灯，简洁现代，在系统托盘小尺寸下识别度更高 |
| 变色位置 | 实心变色 vs 外圈变色 | 外圈变色 | 圆点固定深灰、外圈变色，比实心变色更 subtle 有质感 |
| 绘制方式 | PIL vs 外部 PNG | PIL | 保持无外部依赖，代码内完成所有渲染，部署零额外文件 |
| 圆点颜色 | 纯黑 vs 深灰 | #37474F (Blue Grey 800) | 深灰比纯黑更柔和，与彩色外圈搭配不突兀 |
| 外圈宽度 | 2px vs 3px vs 4px | 3px | 在 64x64 画布上，3px 外圈视觉平衡，16px缩放下依然可见 |

## Implementation

```python
def create_icon_image(color: str = 'green'):
    img = Image.new('RGBA', (64, 64), (0, 0, 0, 0))
    draw = ImageDraw.Draw(img)

    colors = {
        'green': (76, 175, 80, 255),
        'red': (244, 67, 54, 255),
        'yellow': (255, 193, 7, 255),
    }
    c = colors.get(color, colors['green'])

    # 外圈（状态色，3px 宽）
    draw.ellipse([2, 2, 61, 61], outline=c, width=3)
    # 内圆点（深灰色 #37474F）
    draw.ellipse([13, 13, 50, 50], fill=(55, 71, 79, 255))
    # 高光（左上角半透明白色小圆）
    draw.ellipse([18, 18, 28, 28], fill=(255, 255, 255, 50))

    return img
```

## Risks / Trade-offs

- **[显示尺寸风险]** 系统托盘实际显示尺寸可能是 16x16，外圈 3px 在缩放下可能模糊 → 保持圆心和外圈对比度足够高，深灰+彩色组合在各尺寸下都能分辨
- **[颜色盲风险]** 仅靠颜色区分状态 → 考虑未来可增加形状变化辅助（如外圈虚线表示异常），当前阶段保持简约
- **[无迁移成本]** 纯函数替换，无任何外部依赖或数据迁移
